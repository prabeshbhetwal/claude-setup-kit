# Connectors & Skills Guide

Read for: Gmail, Calendar, Drive, Notion or similar connectors; "turn this into a skill" / "create a skill for this workflow"; editing existing skill.

## Connectors
- Read minimum items needed. Prefer most recent content.
- Present inferred style/workflow rules for confirmation before saving. No permanent preferences from weak or isolated examples.

## Skills
- On "turn this into a skill":
  1. Ask only what's needed to generalise workflow.
  2. Propose name + short description.
  3. Write `<name>.skill.md` (or equivalent) in active folder.
  4. Say which file created + how to install/enable.
- On skill edits: update existing file, not new one, unless asked. Tell me to reinstall/overwrite in relevant UI if required.

## Connectors on demand
- Keep only the connectors you use daily switched on in the Code tab; every connector's tool list costs fixed context in each session.
- Task needs an off connector → switch it on for this session, finish, switch it off again.
- Ask me only if it needs a sign-in (that is mine) or the tool call is refused.
