# id|tier|name|licence|what it does|how it helps|what it needs|depends on
caveman|core|Caveman|Apache-2.0|Makes Claude reply in short, clipped sentences. Code, file paths and error messages stay exactly as they are.|Shorter replies cost fewer tokens and are quicker to read. You choose how short: lite, full or ultra.|Nothing.|
adhd|core|i-have-adhd|MIT|Puts the next thing to do at the top of every reply, then short numbered steps.|You can act straight away instead of hunting through paragraphs. Pairs well with Caveman.|Nothing.|
ponytail|core|Ponytail|MIT|Tells Claude to make the smallest change that fully fixes the problem, reusing what already exists.|Smaller code changes: less to review, fewer new bugs.|Nothing.|
context-mode|core|context-mode|Elastic-2.0|When Claude runs a big command or reads a big file, it works on it off to the side and brings back only the answer.|Claude re-reads the whole chat on every turn, so keeping long logs out of it saves tokens on every turn after.|Node.js.|
rtk|core|RTK (Rust Token Killer)|Apache-2.0 + BUSL-1.1 engine (free for own use)|Shortens the output of every terminal command Claude runs (git, tests, builds) while keeping the facts.|Less noise for Claude to read, so fewer tokens per command. It counts what it saves.|Homebrew, or the upstream install script.|
codegraph|core|CodeGraph|MIT|Builds a map of your code: where each function is and what calls what.|Claude finds code in one lookup instead of many searches and file reads.|Node.js + npm.|
graphify|core|Graphify|Apache-2.0|Builds a plain-language overview of a project, its docs and how the parts connect.|Big-picture questions are answered from the overview instead of reading every file.|uv or pipx.|
safety|core|Safe delete (trashmv + rm blocker)|MIT (this kit)|Stops Claude from permanently deleting files. It moves them to ~/_trash/<project>/<date>/ instead.|Anything Claude deletes can be put back.|Python 3.|
indexes|core|Auto index hooks|MIT (this kit)|Keeps the CodeGraph and Graphify maps up to date in the background, for any git project with 10+ source files.|The maps are always fresh without you doing anything.|CodeGraph and Graphify.|codegraph,graphify
measure|core|Token measuring scripts|MIT (this kit)|Scripts that read Claude's local logs and count tokens. A monthly report runs by itself on the 1st.|You see what you used, what the kit saved (per tool where it can be counted) and what you would have used without it. Uses no Claude tokens.|Python 3.|
rules|core|CLAUDE.md template + guides|MIT (this kit)|A rules file plus five short guides that tell Claude when to use each tool you installed.|Without it Claude often forgets the tools exist. Only the tools you picked are mentioned.|You fill in four placeholders (name, place, form of address, English variant).|
supermemory|memory|Supermemory|MIT (plugin)|Brings relevant notes from past chats into each new prompt, and saves new ones.|Claude remembers your decisions and preferences across chats and projects.|A Supermemory account (sign-in on first use).|
cognee|memory|Cognee (local)|Apache-2.0|Builds a private knowledge map of your chats on your own computer.|Answers questions like "what did we decide about X, and why" across projects.|An LLM API key (e.g. Anthropic) billed per use; Python or uv.|
agentmemory|memory|agentmemory|Apache-2.0|A memory server on your computer that Claude can search for past work.|Claude checks what was done before instead of redoing it.|Node.js 20+; you start its server yourself (npx).|
remember|memory|remember|Community licence (no commercial redistribution)|Keeps a running diary of each project's sessions and shows Claude a short summary at the start.|Pick up where you left off, with no account or key.|Nothing.|
routing|routing|Model routing card + lean agents|MIT (this kit)|Tells Claude to use the cheapest model that can do each task, and adds five small helper agents.|Big, tool-heavy jobs go to cheaper helpers. Small jobs are not worth handing off (measured), so Claude does those itself.|Nothing.|
model-selector|routing|Model Selector pack (optional)|Ben AI pack, no licence: in your private copy only, never published|Recommends a model per prompt and routes sub-agents (model-selector, model-router, handoff, cache-clock).|Starts chats on cheaper models when the task allows.|Your private copy of this kit (private/claude-model-selector.zip, made by pack-private.sh) or a zip from Ben AI.|routing
jev|judge|Jev triage (jev, jev-gate, hooks)|MIT (this kit)|Sends long lists (log lines, search results, changes) to a fast outside service that answers yes/no or a score for each.|Claude reads only the items that matter instead of all of them.|A TypeSafe account and TYPESAFE_API_KEY (paid).|
mjudge|judge|mjudge (media judge)|MIT (this kit)|Asks Google's Gemini a yes/no, choice or score question about images, video, audio or PDFs.|Claude can sort media without loading the files into the chat.|GEMINI_API_KEY (free tier exists; free tier may train on inputs).|jev
deliberation|deliberation|Deliberation|MIT|Asks other AI models (GPT, Gemini, Grok or OpenRouter) for a second opinion from inside Claude Code.|An independent check on big decisions, plans and bugs that will not go away.|At least one provider: Codex CLI sign-in (GPT), agy CLI (Gemini), XAI_API_KEY (Grok) or OPENROUTER_API_KEY.|
